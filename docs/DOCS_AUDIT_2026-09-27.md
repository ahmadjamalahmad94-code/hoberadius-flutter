## B. المشاكل الموثّقة وحلولها

### البناء / CI
- **تغيّر 397 ملفًا فجأة** — سببه CRLF بلا `.gitattributes` → أُضيف `eol=lf` و`autocrlf=false`.
- **صور golden فاشلة دخلت المستودع** → حُذفت + gitignore.
- **golden تفشل على لينكس** (antialiasing) → وسم `golden` ويُستثنى في CI.
- **intl 0.20.2 يحتاج Flutter ≥3.29** → تثبيت 3.44.1.
- **plugins بـcompileSdk قديم** → رُفعت إلى 36. **CMake** يُثبَّت مسبقًا.
- **فشل التحليل على CI اليوم** — dio أحدث أضاف `transformTimeout` و`pubspec.lock` لم يكن مُلتزَمًا → set بدل switch + التزام lock.
- **لا بناء APK محلّيًّا** («Unable to establish loopback connection» في JDK) و**لا بناء ويندوز محلّيًّا** (مكوّن ATL) → البناء في السحابة (وظيفتان: APK + Windows zip). ملاحظة: `win-build.log` بتاريخ 06-28 يُظهر بناء ويندوز محلّيًّا ناجحًا، فالعائق ربّما زال.

### أندرويد / Firebase
- **النسخة لا تصل لخادم HTTP** → cleartext + إذن INTERNET في CI.
- **إعداد Firebase يضيع** لأنّ `android/` يُولَّد كلّ مرّة → `tool/configure_android.sh` مصدر الحقيقة (applicationId، minSdk 23، desugaring، google-services).
- **إلغاء الرمز عند الخروج 404** — الرمز في المسار بدل الجسم → DELETE مع body.
- **iOS بلا دفع** — مؤجّل (لا plist).

### ويندوز
- غرفة التصدير لا تظهر (بوّابة عرض 1280 مقابل محتوى ~988) → تُظهَر على أيّ سطح مكتب.
- الغلاف يقفز لتخطيط الهاتف عند التصغير → نقاط كسر 1000/840.
- CMake 4 يرفض Firebase SDK → `CMAKE_POLICY_VERSION_MINIMUM=3.5`.
- مثبّت `dist/` قديم (0.1.0 بمسار قديم) — **مفتوح**.

### عقد API
- «آخر النشاطات» فارغة (مفتاح خاطئ) · العملة ILS بدل عملة الشبكة · نموذج المشترك والباقة يُسقطان حقولًا · قوالب الطباعة تُرسم مختلفة · مفاتيح صلاحيات خام · التقارير بلا فلتر تاريخ · مدّة السرعة المؤقّتة → كلّها أُصلحت في حزيران.
- **اليوم**: quota الاتصالات حُذفت من الخادم · usage-report كان GET (405) · سقف 2000 بطاقة · انهيار عند 413 → أُصلحت في 0.3.0.
- **مفتوح**: فلتر «ما يحتاج انتباه» يرسله التطبيق والباك-إند يتجاهله (لا `attention` في `/accounts`) · مركز الأحداث يستدعي `/events` (business) لا `/events-center`.

### الواجهة / RTL
- ~21 حالة overflow أُصلحت بمسح 71 شاشة × 3 عروض (مدموج).
- **منتقي الوقت أسود ونصوص المفاتيح غير مرئيّة** (ThemeMode.system + داكن نصف مُنجز) · **زرّ الرجوع يُغلق التطبيق** · «حبوب بنفسجيّة بلا نصّ» · مساحات ضائعة · جدول الحزم عريض · لا معاينة حيّة → كانت على الفرع غير المدموج، **دُمجت اليوم**. بقي ~23 ملفًا تستعمل Switch/FilterChip القديم بدل `HubSwitchRow`.

### الأمان
- انتهاء الرموز (7 أيام) وdev-token وCORS → مُنفَّذة في الباك-إند.
- **مفتوح**: `/api/admin/login` يمنح `admin:full` لكلّ مدير أيًّا كان دوره؛ بوّابة super-only على `/admins` فقط (وسُدّت اليوم فجوة سلّة المحذوفات على فرع `security/recycle-bin-admin-gate`). لا `/api/admin/refresh`.

### الإشعارات
- مركز إشعارات + جرس (استطلاع 60ث) · toasts ويندوز لا تُغرق بالقديم · الدفع صار مركزيًّا عبر لوحة التراخيص (الريدياس يحوّل ولا يخزّن).

## C. القرارات التصميميّة وأسبابها
1. لا WebView ولا بيانات وهميّة؛ API أوّلًا ثمّ شاشة (كلّ الويب ينتقل إلى فلاتر أصليّ).
2. فلاتر يستدعي Flask JSON فقط، بلا منطق عمل ولا وصول مباشر لقاعدة أو راوتر.
3. `not_implemented`/`dry_run` تُعرض «غير متاح» لا نجاحًا.
4. كود واحد للجوّال وويندوز.
5. إعادة التصميم واجهة فقط بلا تغيير API.
6. ألوان التصميم مطابقة حرفيًّا لـ`hub_tokens.css`؛ ممنوع `Color(0xFF…)` خارج `lib/core/theme/`.
7. خطّ Cairo للواجهة، وAlmarai مضمَّن لمحرّك البطاقات وPDF ليطابق الويب.
8. RTL عربيّ مفروض.
9. الوضع الداكن: قُرّر ثمّ نُقض إلى فاتح فقط بعد مراجعة الهاتف (مدموج اليوم).
10. القائمة: شريط كامل ≥1000، rail ≥840، وشريط سفليّ تحت ذلك؛ ومرآة 1:1 لشريط الويب بلا روابط ميتة.
11. PDF يُولَّد في الباك-إند ليكون مطابقًا بتًّا للويب.
12. `android/` و`windows/` خارج git ويُولَّدان بـ`flutter create`.
13. APK release موقّع بمفتاح debug ليُثبَّت مباشرة.
14. البناء في السحابة بسبب عوائق الجهاز المحلّيّ.
15. FCM مركزيّ: تطبيق واحد `com.hoberadius.app` ومشروع Firebase واحد في لوحة التراخيص؛ مفتاح Admin SDK لا يُحفظ في مستودع التطبيق أبدًا.
16. Bearer من `/api/admin/login` + `X-API-Key` لكلّ نشر؛ إعادة المحاولة للطرق idempotent فقط.
17. بوّابة الجودة: لا كسر تصميم على 360/600/1280 مع RTL، ولا عناصر وهميّة.
18. العمليّات الخطرة تتطلّب معاينة + عبارة تأكيد.
